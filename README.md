# 梅香寄北堂

送给妈妈的生日古风小短片（约 3 分钟，1920×1080）。

- **成片**：[`output/梅香寄北堂.mp4`](output/梅香寄北堂.mp4)，可直接发微信
- **网页版**：用浏览器打开 `src/index.html`，点击播放

## 内容

| 段落 | 画面 | 配乐 |
| --- | --- | --- |
| 开场 | 宣纸、远山、明月；一枝墨梅生长、红梅次第开放；题字“梅香寄北堂”，钤印“欣宜” | 古筝刮奏，题字每落一笔一个音 |
| 书信 | 梅花笺上竖排朱丝栏，信一字一字以墨迹写出 | 古筝主旋律（D 宫五声调式） |
| 题诗 | 诗直接题在梅花图上，落款“丙午秋 欣宜敬书”并盖印；“映雪红英”“临风梅蕊”中的“红”“梅”用朱砂色点出 | 每联两小节 |
| 结尾 | 花苞全部绽放，落英缤纷，“妈妈 · 生日快乐” | 古筝版《生日快乐》 |

诗的四联各有呼应的画面：金风送桂（桂花随风飘过）、映雪红英（落雪）、窗外常存万里光（月华流照）、愿得四时皆胜景（金光点点）。

## 修改与重新生成

文字都在 `src/content.js`。改动文字后：

```bash
python3 tools/fetch_fonts.py   # 下载新字的字形（Google Fonts 子集）
tools/build.sh                 # 生成配乐、渲染画面、合成 output/梅香寄北堂.mp4
```

依赖：Node + Playwright（Chromium），Python 3 + `numpy scipy imageio-ffmpeg`。

- `src/film.js` 画面引擎，每一帧都是时间的纯函数，可实时播放也可逐帧渲染
- `tools/music.py` 配乐合成（加法合成模拟古筝），按画面导出的时间线对齐
- `tools/stills.mjs` 渲染指定时间点的静帧，方便检查画面

字体：马善政楷书、志莽行书、霞鹜文楷，均为 SIL Open Font License。
