# 梅香寄北堂

送给妈妈的生日古风小短片（约 3 分钟，1920×1080）。

- **成片**：[`output/梅香寄北堂.mp4`](output/梅香寄北堂.mp4)，可直接发微信
- **网页版**：用浏览器打开 `src/index.html`，点击播放

## 内容

| 段落 | 画面 | 配乐 |
| --- | --- | --- |
| 开卷 | 案上一卷手卷徐徐展开，画心里已是远山与秋月；镜头推近入画 | 卷轴展开时一串刮奏 |
| 题字 | 一枝红梅自右上角“生长”出来（先枝后花）；题字“梅香寄北堂”，钤印“欣宜” | 题字每落一笔一个音 |
| 鸿雁传书 | 题字随风化作花瓣；雁阵飞过月亮；一阵花雨送来梅花信封，镜头推向信笺 | 雁过月前几声高音 |
| 书信 | 左边一幅竖画、右边朱丝栏信笺，信一字一字写出；每页换一幅与内容呼应的画：月下湖（身在远方）、灯火人家（家）、日出远山（前路）、三亚海边（三亚之行）、红日梅花（祝愿）、红梅（生日）；读完一页，字随风化作花瓣 | 古筝主旋律（D 宫五声调式） |
| 题诗 | 每联换一幅景：秋景与桂花（金风送桂）、雪中梅与红梅花雨（映雪红英）、书卷与窗光（书中/窗外）、春夏秋冬四景轮转（四时皆胜景），最后回到梅花图，如意结垂下；落款“丙午秋 欣宜敬书”并盖印；“红”“梅”二字用朱砂色点出 | 每联两小节 |
| 结尾 | 红梅满枝，祥云、天灯冉冉升起，“妈妈 · 生日快乐”；最后镜头拉远，卷轴合上 | 古筝版《生日快乐》 |

## 修改与重新生成

文字都在 `src/content.js`。改动文字后：

```bash
python3 tools/fetch_fonts.py   # 下载新字的字形（Google Fonts 子集）
tools/build.sh                 # 生成配乐、渲染画面、合成 output/梅香寄北堂.mp4
```

依赖：Node + Playwright（Chromium），Python 3 + `numpy scipy imageio-ffmpeg pillow`。

网页预览：`python3 -m http.server -d src 8000`，然后打开 http://localhost:8000 。

- `src/film.js` 画面引擎，每一帧都是时间的纯函数，可实时播放也可逐帧渲染
- `src/assets/` 画面素材（GPT 生成的插画，经 `tools/prep_assets.py` 裁切、拆分、压缩；原图放在 `assets/source/`，因体积大未提交）
- `tools/music.py` 配乐合成（加法合成模拟古筝），按画面导出的时间线对齐
- `tools/stills.mjs` 渲染指定时间点的静帧，方便检查画面

字体：马善政楷书、志莽行书、霞鹜文楷，均为 SIL Open Font License。
